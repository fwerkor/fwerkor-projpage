PROJECT NOTES

项目概览

系统定位

CapOS 将 OpenWrt 的轻量系统基础扩展为面向服务器的完整环境，覆盖网络、存储、远程管理、应用生命周期和浏览器端 WebDesktop。

Lightweight base保留小型设备和边缘环境需要的低资源占用。
Web management常见系统操作和应用入口集中到浏览器界面。

应用与兼容

系统组件继续由 CapOS/OpenWrt 包体系管理，用户应用通过 Snap 生态安装；systemd-on-procd 提供常见 systemd 命令与 unit 边界兼容。

Snap Store面向通用 Linux 应用生态。
Web discovery自动发现并接入应用暴露的 Web 服务。

部署路径

项目覆盖多架构固件、OCI 系统镜像以及与 ArgosFS 的根文件系统集成。GitHub Releases 和项目官网提供公开下载与文档入口。
