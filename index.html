DIFFUSION RUNTIME01

CID

Continuous Interaction Diffusion 面向扩散语言模型的异步工具增强推理。它把事实、思考和最终显示拆成相互协同的状态通道，让外部信息可以在去噪仍在进行时并行获取，并在返回后持续修正中间认知和最终输出。项目同时包含模型接口、运行时、训练数据结构和评测工具，当前公开工作重点是只读工具与异步感知绑定。

FILESYSTEM02

ArgosFS

ArgosFS 是一个以 Rust 实现的自驱动纠删码文件系统，面向本地异构磁盘、根文件系统和长期运行场景。它提供 FUSE 前端、原始块设备与 loop 后端、Reed–Solomon 冗余、校验、修复、压缩、加密和磁盘健康感知，并通过 autopilot 将巡检、重平衡和部分维护流程自动化。项目也包含与 CapOS rootfs 的集成路径。

SERVER OS03

CapOS

CapOS 是基于 OpenWrt 技术栈构建的开源服务器操作系统，目标是把轻量系统、浏览器管理界面和常见服务部署整合到同一套环境中。系统覆盖网络、存储、应用管理与 WebDesktop，并支持从小型设备到通用 x86/ARM 服务器的部署。当前工程也在推进 Snap 应用集成、OCI 系统镜像与 ArgosFS 根文件系统路径。

LLM SYSTEMS04

CacheReforge

CacheReforge 研究持续更新轻量适配器时的陈旧 KV Cache 恢复问题。它把缓存表示成逐层混合版本对象，并结合适配器锚点、敏感度、累计漂移和可执行重启边界，在直接复用、有限重算与完整后缀恢复之间选择。公开论文在持续 LoRA 更新、长上下文 HotpotQA 与 2WikiMQA 工作负载上评估了这种有界恢复机制。
